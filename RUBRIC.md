# Evaluation Rubric (100 points)

| Area | Points | What we look for |
|---|---|---|
| Frontend Craft & Functionality | 30 | All functional requirements work; edge cases handled (empty states, rapid input, long tag names); responsive layout with smooth tag wrapping. |
| Code Architecture & Hygiene | 20 | Clean directory structure, sensible state separation, meaningful names, minimal re-renders and dependencies, proper event cleanup. |
| Accessibility & UX Detail | 15 | Smooth keyboard navigation, thoughtful ARIA attributes and labels, clean focus states. |
| Technical Writing Clarity | 25 | Simple, accurate explanations; logical flow; good use of headings, bullets and code snippets. |
| Developer Empathy & Tone | 10 | Professional, instructive, engaging; no hallucination or generic filler. |
| **Total** | **100** | |

Basic tests are a bonus and can lift borderline scores in Craft and Architecture.
